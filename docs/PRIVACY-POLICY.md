# 星象仪 (Stellarium) 隐私政策

**最后更新日期：** 2026-09-08

**修订状态：** 审核整改草案。2026-09-08 已在 AppGallery Connect 原协议中保存对应修订，尚未生成发布；平台服务器存储模板与当前离线行为的冲突仍待处理。SN 调用来源及同意门禁已分项核验，不能据此保证 Release 全路径或复审通过。本地文件不自动更新托管政策。

星象仪基于 Stellarium 开源项目，遵循 GPLv2 许可证。星图计算在设备本地完成；主动使用定位、设备转向、保存和分享时，会在本机处理下述数据。“不上传”不等于“不读取、不处理”。

## 1. 观测地点

- **用途和数据：** 读取系统提供的经纬度及可用海拔，用于计算当前地点可见的星空。
- **获取时机：** 同意隐私政策后，主动点击自动定位并授权定位权限时获取一次。相关权限为 ohos.permission.APPROXIMATELY_LOCATION 和 ohos.permission.LOCATION。
- **控制：** 拒绝或获取失败时保留原观测地点，可继续离线城市搜索和手动选点；不后台持续定位或建立轨迹。
- **保存：** 选定地点保存在设备本地，不向本应用服务器上传。清除应用数据可删除本地保存的地点；自行导出的文件需另行删除。

## 2. 设备姿态传感器

“转动设备浏览星空”功能根据设备支持情况读取以下类型的数据：

- **重力传感器：** 三轴重力分量，用于辨别设备上下方向、稳定地平线。
- **磁场传感器：** 三轴磁场分量，用于罗盘方向校准。
- **旋转矢量传感器：** 旋转分量，用于计算设备姿态并调整星图视角。
- **方向传感器：** 在旋转矢量不可用时提供方向角，用于设备朝向计算。
- 系统融合姿态数据可能使用加速度计、陀螺仪和磁场传感器。应用声明的相关权限为 ohos.permission.ACCELEROMETER 和 ohos.permission.GYROSCOPE；权限名称不能代替具体数据类型的说明。

**获取时机：** 同意本政策后，主动开启上述功能时订阅。关闭功能、进入后台或撤回同意时停止订阅；不开启时仍可通过触摸浏览星图。

**处理方式：** 测量值在本机内存实时计算，不建立传感器采样文件，不向本应用服务器上传。常规姿态诊断仅保留功能状态、调用次数等信息，不记录原始方向角、重力或磁场测量值。主动导出配置、会话或诊断资料时，请检查其中包含的观测位置和视角等内容后再分享。

## 3. 设备序列号（SN）及基础运行组件

星图、观测地点和设备转向功能不需要以硬件序列号识别用户。应用不以设备标识建立用户画像或进行广告追踪。基础运行组件初始化仅允许在同意当前隐私政策后执行。

Qt 6.12.0 基础运行环境用于承载本地星图引擎、图形显示和操作系统适配。其初始化通过系统设备信息接口尝试读取操作系统及软硬件参数，包括设备序列号（SN）和 UDID；是否返回有效值由系统权限控制。本应用不增加受限设备标识权限，不向本应用服务器或组件提供方上传这些字段。该调用属于同意当前隐私政策后的 SDK 初始化，不是连接外设时才调用，星图计算本身不依赖硬件标识。

设备信息在本机运行上下文处理；系统拒绝返回时，不将接口调用描述为成功取得标识。上游组件信息：[Qt](https://www.qt.io/)，提供方隐私说明：[The Qt Company](https://www.qt.io/terms-conditions/privacy-policy)。上述链接不代表本应用接入其广告或统计服务。

## 4. 本地保存、导出和分享

配置、观测列表等默认存储在应用沙箱；主动保存到相册、选择导出目录或分享时，按系统选择结果交给相应位置或应用。本应用不自动上传这些文件。接收应用如何处理分享内容，适用其隐私规则及您的后续操作。清除应用数据可删除沙箱资料，相册和导出文件需在对应位置另行删除。

主动导入仅处理用户选定的文件。主动点击复制时向系统剪贴板写入所选内容，不因剪贴板变化通知自动读取其中内容。分享配置、会话或诊断资料前，请确认其中包含的观测地点、视角等信息。

## 5. 离线及诊断说明

位置页新增“华为地图”可选在线模式。只有用户主动选择该模式时，应用才通过 HarmonyOS Map Kit 请求地图底图和地图组件服务；默认仍使用随包离线地图，加载失败可立即回退。华为地图可能处理地图组件所需的粗略/精确位置、地图交互和匿名服务信息，具体以华为地图隐私说明为准；本应用不把 SN、UDID、账号或观测资料附加到地图请求，也不建立自有地图轨迹。文化分布图继续使用本地研究叠加层，不替换为现代行政边界地图。

当前版本不提供应用内星表自动下载，不包含广告或第三方追踪 SDK。系统定位、华为地图、应用市场隐私服务及用户主动选择的分享接收应用由系统或相应服务方处理，本应用不代其承诺完全不联网。关闭华为地图模式后，位置选点回到本地离线地图。

如您主动开启天象提醒，应用仅把您选择的标题、内容和事件时间交给鸿蒙系统本地通知/代理提醒服务，由系统在设备上显示；本功能不读取或上传设备序列号、位置信息，不使用应用服务器推送。您可以在系统通知设置中关闭，或在应用内清理已注册提醒。

应用保留本机运行日志用于排查启动、输入阻塞等故障，不自动上传；本轮新增输入阻塞探针仅记录耗时与初始化状态，不记录触摸坐标、位置或设备序列号。请勿在公开反馈中提交未经检查的原始日志。

## 6. 隐私选择

可在设置中撤回隐私同意，应用停止设备姿态订阅并退出；再次启动须重新确认。定位权限可在系统设置中管理。政策更新涉及已同意内容变化时，通过应用市场隐私管理服务更新版本并重新取得相应同意。

入口为“更多→设置→设备与隐私→撤回隐私同意”。观测地点、配置、观测列表可在相应功能中查看或修改；本应用无注册账户，无需账号注销。未来新增联网服务前，另行说明实际数据类型、接收方、用途、期限及用户选择，不因备案完成而自动开启上传。

儿童使用定位和分享功能时建议由监护人指导；本应用不进行广告追踪或用户画像。
