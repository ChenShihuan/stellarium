2026-09-23 已按用户授权部署到上海 ECS，正式域名为 `https://skyinstrument.cn`。网站备案控制台核实编号为 `新ICP备2026008516号-1`；网站备案不代替 APP 备案或应用市场审核。后续网络入口、收费服务与应用签名变更仍须单独确认。

## 本机预览与构建

```sh
cd /Users/jiexuanyang/stellarium-src/website
npm ci
npm run dev -- --host 127.0.0.1
```

打开启动时打印的本地地址。检查与生成静态文件：

```sh
npm run lint:site
npx tsc --noEmit
npm run build
node scripts/check-static.mjs
```

仅发布 `dist/client/`，不发布源码、node_modules、dist/server、身份材料、证书或环境文件。服务器只需静态文件服务，不需要 Node/React 服务端；构建机器与线上服务器分离。

已有构建时，可运行 `node scripts/preview.mjs` 预览真实静态产物，地址为 `http://127.0.0.1:3000/`。此服务器仅供本机预览，不代替生产 nginx，不开放局域网或公网。

## 页面与素材

- 首页：原创、可拖动星群视觉，非真实星图；左右拖动/方向键、暂停/继续、Home 重置。触屏保留竖向滚动。系统减少动态效果时自动静止；离开可见区域、后台暂停绘制。
- 功能展示：维护者提供的两张实际应用截图，未裁切、未重绘。页面惰性载入，不下载第三方素材。
- 隐私说明、开源致谢：独立静态页面。Github 和 Stellarium 外链仅在主动点击后打开，并禁用 opener。
- 发布区提供华为应用市场 App Linking 入口，目标包名为 `com.joinother.skyinstrument`；若应用市场尚未公开详情页，用户可回退搜索“星象仪”。该入口不宣称华为认证或推荐。
- 默认系统字体，无远程字体、统计、广告、账户、支付、上传接口。
- 当前以中文网站备案，因此网站正文为简体中文，不自动增加未经备案核对的新业务/语种。
- 首页参考 OpenAI Astra 页面星光的动感与留白，不复制其数字、标识、源代码、图片或视频。页面星群不是应用中的模拟器。

## 静态路由与检查

`output: 'export'` 输出 `index.html`、`privacy.html`、`credits.html`、`404.html` 和本地资源。保留原生链接，避免静态 nginx 必须实现 RSC 客户端导航接口。图片直接引用本地文件，不依赖在线图片优化器；Canvas 无等价 img 交互元素。因此本站范围内明确关闭对应 Next/语义替代建议，不关闭其他正确性检查。

脚手架自带的未使用 `components/ui/` 与 `hooks/use-mobile.ts` 存在独立的全库 lint 告警；`lint:site` 检查本次实际页面、交互和构建配置。不为解决脚手架告警修改组件库源文件。

生产配置见 `deploy/nginx-tls.conf`，其中的静态路由规则：

```nginx
rewrite ^/(privacy|credits)/$ /$1 permanent;
location / { try_files $uri $uri.html $uri/ =404; }
error_page 404 /404.html;
location ~ /\. { deny all; }
```

生产环境还需 HTTPS、正确 MIME 类型、访问日志策略、缓存策略、安全响应头、只允许 GET/HEAD、部署原子切换和回滚。先验证 CSP 与静态框架内联启动脚本兼容，不照搬会阻断页面的 CSP。
